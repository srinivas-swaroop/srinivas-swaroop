## 239. Sliding Window Maximum

---

# 1. Problem Understanding

You are given:

* An integer array **nums**
* An integer **k** representing the size of a sliding window.

A **sliding window** of size `k` starts at the **beginning of the array**.

At every step:

1. Look at the **k elements inside the window**
2. Find the **maximum element**
3. Slide the window **one step to the right**

Continue until the window reaches the end.

### Example

Input

```
nums = [1,3,-1,-3,5,3,6,7]
k = 3
```

Windows:

```
[1 3 -1] -> 3
[3 -1 -3] -> 3
[-1 -3 5] -> 5
[-3 5 3] -> 5
[5 3 6] -> 6
[3 6 7] -> 7
```

Output

```
[3,3,5,5,6,7]
```

# 4. Different Coding Approaches

---

# Approach 1 — Brute Force

### Intuition

For every window:

1. Iterate through the **k elements**
2. Find maximum

### Time Complexity

```
O(n * k)
```

### Pseudocode

```
for i from 0 to n-k
    max = nums[i]
    for j from i to i+k-1
        max = max(max, nums[j])
    result[i] = max
```

### Java Code

```java
class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {

        int n = nums.length;
        int[] res = new int[n - k + 1];

        for(int i = 0; i <= n - k; i++) {

            int max = nums[i];

            for(int j = i; j < i + k; j++) {
                max = Math.max(max, nums[j]);
            }

            res[i] = max;
        }

        return res;
    }
}
```

### Complexity

```
Time  : O(nk)
Space : O(1)
```

---

# Approach 2 — Priority Queue (Heap)

### Intuition

Use **Max Heap** to keep track of maximum in window.

Steps:

1. Add elements to heap
2. Remove elements outside window
3. Top of heap = max

### Pseudocode

```
use maxHeap

for i from 0 to n-1
    add nums[i]

    if i >= k-1
        result add heap top
        remove nums[i-k+1]
```

### Java Code

```java
import java.util.*;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {

        PriorityQueue<Integer> pq =
            new PriorityQueue<>(Collections.reverseOrder());

        int n = nums.length;
        int[] res = new int[n-k+1];

        for(int i = 0; i < n; i++) {

            pq.add(nums[i]);

            if(i >= k) {
                pq.remove(nums[i-k]);
            }

            if(i >= k-1) {
                res[i-k+1] = pq.peek();
            }
        }

        return res;
    }
}
```

### Complexity

```
Time : O(n log k)
Space: O(k)
```

# Approach 3 — Optimal (Monotonic Deque)

This is the **expected interview solution**.

### Intuition

Maintain a **deque of indices** such that:

* Elements are **in decreasing order**
* Front always contains **maximum**

Steps:

1. Remove elements **outside window**
2. Remove smaller elements from **back**
3. Add current index
4. First element = max

### Pseudocode

```
create deque

for i = 0 → n-1

    remove indices outside window

    while deque not empty and
          nums[last] < nums[i]
          remove last

    add i

    if i >= k-1
        result = nums[deque.first]
```

### Java Code

```java
import java.util.*;

class Solution {
    public int[] maxSlidingWindow(int[] nums, int k) {

        int n = nums.length;
        int[] res = new int[n-k+1];

        Deque<Integer> dq = new ArrayDeque<>();

        for(int i = 0; i < n; i++) {

            while(!dq.isEmpty() && dq.peekFirst() <= i-k) {
                dq.pollFirst();
            }

            while(!dq.isEmpty() &&
                  nums[dq.peekLast()] < nums[i]) {
                dq.pollLast();
            }

            dq.offerLast(i);

            if(i >= k-1) {
                res[i-k+1] = nums[dq.peekFirst()];
            }
        }

        return res;
    }
}
```

### Complexity

```
Time  : O(n)
Space : O(k)
```

Each element enters and leaves deque **once**.

# 6. Common Mistakes Students Make

1️⃣ Forgetting result size

```
n - k + 1
```

2️⃣ Removing wrong index from deque.

3️⃣ Storing **values instead of indices**.

4️⃣ Not checking **window bounds**.

5️⃣ Off-by-one errors.

6️⃣ Using brute force → **TLE**.
