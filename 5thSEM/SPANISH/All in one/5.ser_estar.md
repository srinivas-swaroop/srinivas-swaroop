# ⭐ SER vs ESTAR — SUPER EASY RULE

✔ **SER = permanent / identity / nature**
✔ **ESTAR = temporary / condition / location**

Think like this:

### 🔵 **SER = WHAT something IS** (its identity)

### 🟢 **ESTAR = HOW or WHERE something is** (its condition or position)

That’s the whole logic.

Now let’s break it down.

---

# 🔵 **WHEN TO USE SER**

Use **SER** for things that are **permanent, long-lasting, or define a person/thing**.

### 🟦 1. **Identity (who/what someone is)**

* Yo **soy** estudiante. → I am a student.
* Él **es** profesor. → He is a teacher.

### 🟦 2. **Origin / Nationality**

* Soy de India. → I am from India.
* Ellos **son** españoles. → They are Spanish.

### 🟦 3. **Characteristics (long-term)**

* Ella **es** alta. → She is tall.
* El coche **es** caro. → The car is expensive.

### 🟦 4. **Time & dates**

* Hoy **es** lunes. → Today is Monday.
* **Son** las cinco. → It’s 5 o’clock.

### 🟦 5. **Profession**

* Mi padre **es** ingeniero. → My father is an engineer.

### 🟦 6. **Possession**

* Este libro **es** mío. → This book is mine.

### 🟦 7. **Material**

* La mesa **es** de madera. → The table is made of wood.

---

# 🟢 **WHEN TO USE ESTAR**

Use **ESTAR** when the situation is **temporary, changing, or location**.

### 🟩 1. **Location (always ESTAR!)**

* Estoy en casa. → I am at home.
* El libro **está** en la mesa. → The book is on the table.

(Even if permanent, location NEVER uses “ser”)

### 🟩 2. **Temporary conditions**

* Estoy cansado. → I’m tired.
* Ella **está** enferma. → She is sick.

### 🟩 3. **Emotions / feelings**

* Estoy feliz. → I’m happy.
* ¿Estás triste? → Are you sad?

### 🟩 4. **Temporary appearance**

* Ella **está** guapa hoy. → She looks pretty today.
  (Not always guapa, but right now yes)

### 🟩 5. **Progressive actions**

(estar + gerundio)

* Estoy estudiando. → I am studying.
* Ellos están hablando. → They are talking.

---

# ⭐ SUPER SIMPLE FORMULA

## 🔵 **SER = PERMANENT**

* identity
* profession
* description
* nationality
* time/date
* material
* ownership

## 🟢 **ESTAR = TEMPORARY**

* feelings
* condition
* location
* ongoing action

---

# ⭐ THE MOST IMPORTANT TRICK

### 👉 If it answers **WHAT is it?** → use **SER**

### 👉 If it answers **HOW/WHERE is it?** → use **ESTAR**

# ⭐ **PRESENT TENSE (MOST IMPORTANT)**

# 🔵 **SER – to be (PERMANENT)**

| Pronoun       | Form      |
| ------------- | --------- |
| yo            | **soy**   |
| tú            | **eres**  |
| él/ella/usted | **es**    |
| nosotros      | **somos** |
| vosotros      | **sois**  |
| ellos/ustedes | **son**   |

**Examples:**

* Yo **soy** estudiante.
* Ella **es** alta.

---

# 🟢 **ESTAR – to be (TEMPORARY / LOCATION)**

| Pronoun       | Form        |
| ------------- | ----------- |
| yo            | **estoy**   |
| tú            | **estás**   |
| él/ella/usted | **está**    |
| nosotros      | **estamos** |
| vosotros      | **estáis**  |
| ellos/ustedes | **están**   |

**Examples:**

* Yo **estoy** cansado.
* El libro **está** en la mesa.
