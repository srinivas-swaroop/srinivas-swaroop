# ⭐ **2. WHY these verbs are used (super important)**

### i. **me levanto**

→ “Getting up” = reflexive action (levantarse)
“yo” → me levanto

### ii. **estudia**

→ “studies english” = estudiar
Marta → ella → estudia

### iii. **se levantan**

→ “they get up” = reflexive
they = se levantan

### iv. **tiene**

→ “has a new house” = possession → tener
ella → tiene

### v. **bebemos**

→ “we drink tea every day” = beber
nosotros → bebemos

### vi. **trabaja** and **es**

* trabajar = works in a company
* ser = profession (“is a receptionist”)

### vii. **me lavo**

→ reflexive (I wash myself/my hands)

### viii. **tiene**

→ possession → “has many flowers”

### ix. **es**

→ description / identity → “is a city”
Use **ser**

### x. **está**

→ location → “is located in the center”
Use **estar**

# ⭐ **3. HOW TO FIND THE CORRECT VERB (THE REAL TRICKS)**

This is the MOST important part.

## 🔵 **TRICK 1: Ask yourself — WHAT is the sentence talking about?**

| Meaning in English           | Spanish Verb   |
| ---------------------------- | -------------- |
| to be (permanent)            | **ser**        |
| to be (location / temporary) | **estar**      |
| to have / possession         | **tener**      |
| to wake up / get up          | **levantarse** |
| to wash                      | **lavarse**    |
| to drink                     | **beber**      |
| to eat                       | **comer**      |
| to study                     | **estudiar**   |
| to work                      | **trabajar**   |
| to buy                       | **comprar**    |

🔍 So read the sentence and think:
**What action or idea is this?**

---

## 🟢 **TRICK 2: Check if the action is REFLEXIVE**

Reflexive = action done to **yourself**.
LOOK FOR:

* waking up
* washing
* getting up

These always use:
**me, te, se, nos, os, se**

Example:
"Los fines de semana yo ______ a las diez."
Meaning = “I get up” → reflexive → **levantarse**
yo → **me levanto**

---

## 🔴 **TRICK 3: For SER vs ESTAR — Use the GOLD RULE**

### ✔ SER = permanent

### ✔ ESTAR = temporary / location

Examples:

* "Sevilla ___ una ciudad" → definition → **es**
* "El monumento ___ en el centro" → location → **está**

---

## 🟡 **TRICK 4: If sentence has AGE, POSSESSION, NEED → TENER**

* tiene
* tienen
* tengo
* tenemos

Example:
"Ella ___ una casa nueva."
= She **has** → **tiene**

---

## 🔹 **TRICK 5: If sentence has frequency (every day, always), it’s usually an action**

Use regular verbs:

* estudiar
* trabajar
* beber
* comer
* comprar

Example:
"Marta ___ inglés todos los días."
→ action repeated daily → **estudia**

# ⭐ 4. HOW TO FIND THE RIGHT CONJUGATED FORM (SUPER EASY)**

Just follow this 3-step method:

### STEP 1 — Identify the verb

Ex: levantarse

### STEP 2 — Identify the subject

yo → tú → él → ella → nosotros → etc.

### STEP 3 — Apply the pattern

Use AR / ER / IR endings OR irregular form.

Example:
Verb = beber
Subject = nosotros
Beber → ER verb → ending = **emos**

→ Nosotros **bebemos**
