# ⭐ 1. BASIC RULE — “¿Qué hora es?” (What time is it?)

## ONLY two structures exist:

### ✔ **1 → “Es la…”** (ONLY for 1:00)

* **Es la una.** → It’s 1:00
* **Es la una y media.** → It’s 1:30
* **Es la una y cuarto.** → It’s 1:15

### ✔ **All other hours → “Son las…”**

* **Son las dos.** → It’s 2:00
* **Son las tres.** → It’s 3:00
* **Son las nueve.** → It’s 9:00

👉 MUST memorize:
**1 = ES LA**
**2–12 = SON LAS**

---

# ⭐ 2. MINUTES — Add “y + minutes”

**English: 2:10 → Spanish: Son las dos y diez**

Examples:

* 3:15 → **Son las tres y quince**
* 4:20 → **Son las cuatro y veinte**
* 6:05 → **Son las seis y cinco**
* 7:12 → **Son las siete y doce**

---

# ⭐ 3. SPECIAL WORDS (VERY IMPORTANT)

### ✔ **y cuarto = :15**

Son las tres y cuarto. → 3:15

### ✔ **y media = :30**

Son las cinco y media. → 5:30

### ✔ **menos cuarto = :45**

Son las ocho menos cuarto. → 7:45 (quarter to 8)
**Meaning:** 8 minus 15 minutes.

---

# ⭐ 4. “MENOS” FOR TIMES 31–59

Use this trick:

### **If minutes > 30 → USE “menos”**

English: 9:50
Spanish: **Son las diez menos diez.**
(10 minus 10 minutes)

More examples:

* 5:40 → **Son las seis menos veinte.**
* 7:55 → **Son las ocho menos cinco.**
* 11:45 → **Son las doce menos cuarto.**

---

# ⭐ 5. MIDNIGHT + NOON

| Spanish           | English       |
| ----------------- | ------------- |
| **Es medianoche** | It’s midnight |
| **Es mediodía**   | It’s noon     |

---

# ⭐ 6. AM / PM (Three ways)

### ✔ A. Using “de la mañana / tarde / noche”

* 7:00 a.m. → **Son las siete de la mañana.**
* 3:00 p.m → **Son las tres de la tarde.**
* 9:00 p.m → **Son las nueve de la noche.**

---

### ✔ B. Using 24-Hour Clock (for schedules, trains, flights)

Simple:

* 13:00 → **las trece horas**
* 18:30 → **las dieciocho treinta**

---

### ✔ C. With “por la mañana / tarde / noche” (general time)

* Estudio **por la mañana**. → I study in the morning.

---

# ⭐ 7. TRICK FOR ALL TIMES

This rule will make it SUPER EASY:

### ✔ If the minute number **≤ 30** → use **Y**

Example: 4:25 → Son las cuatro **y** veinticinco

### ✔ If the minute number **> 30** → use **MENOS**

→ go to the NEXT hour
Example: 4:40 → Son las cinco **menos** veinte
(20 minutes before 5)

---

# ⭐ 8. ASKING & ANSWERING TIME

### ✔ Asking:

* **¿Qué hora es?** → What time is it?
* **¿A qué hora…?** → At what time…?

### ✔ Answering:

* **Es la…** (for 1:00)
* **Son las…** (for all others)

Examples:

* ¿A qué hora estudias?
  → **Estudio a las seis.**
* ¿A qué hora comes?
  → **Como a la una.**
