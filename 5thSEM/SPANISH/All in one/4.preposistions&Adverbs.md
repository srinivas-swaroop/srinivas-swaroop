# 🎯 **1. What are Demonstrative Adjectives?**

They show **distance** between the speaker and the object:

| Distance               | English                            | Masculine               | Feminine                  |
| ---------------------- | ---------------------------------- | ----------------------- | ------------------------- |
| **Near (close)**       | this / these                       | **este**, **estos**     | **esta**, **estas**       |
| **Medium (a bit far)** | that / those                       | **ese**, **esos**       | **esa**, **esas**         |
| **Far (very far)**     | that over there / those over there | **aquel**, **aquellos** | **aquella**, **aquellas** |

---

# 🔵 **2. How to Know If It Is Masculine or Feminine?**

### ✔ Check the noun it describes:

* Ends in **-o** → usually **masculine**
* Ends in **-a** → usually **feminine**
* Plural **-os** → masculine plural
* Plural **-as** → feminine plural

Example:
**cuadro** → ends in *-o* → masculine → use **aquel / ese / este**

# 🔥 **4. Examples to Understand Them Clearly**

### ✔ **Masculine examples**

* **este libro** → this book (near me)
* **ese libro** → that book (a bit far)
* **aquel libro** → that book over there (very far away)

### ✔ **Feminine examples**

* **esta mesa** → this table
* **esa mesa** → that table
* **aquella mesa** → that table over there

# 🧠 **5. Your Questions Answered**

### ❓ **1. “Students are not female right?”**

Many classes have boys + girls.
But **if the word ends in -as**, it is **feminine plural**, meaning **female students**.

* **unas estudiantes** = some **female** students
* **unos estudiantes** = some **students (mixed or male)** ← this one is correct for general
