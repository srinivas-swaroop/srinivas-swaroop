# 🔥 **1. ALL SPANISH QUESTION WORDS + MEANINGS**

| Spanish                 | Meaning                 | Used to ask about…     |
| ----------------------- | ----------------------- | ---------------------- |
| **¿Qué?**               | What?                   | things, activities     |
| **¿Quién? / ¿Quiénes?** | Who?                    | people                 |
| **¿De quién?**          | Whose?                  | possession             |
| **¿Cuál? / ¿Cuáles?**   | Which? / What?          | choices, specific info |
| **¿Dónde?**             | Where?                  | places                 |
| **¿Adónde?**            | To where? (destination) | direction              |
| **¿Cuándo?**            | When?                   | time/date              |
| **¿Cómo?**              | How?                    | manner / description   |
| **¿Por qué?**           | Why?                    | reason                 |
| **¿Para qué?**          | For what purpose?       | purpose                |
| **¿Cuánto/a/os/as?**    | How much/many?          | quantity               |

# 🔥 **2. GENERAL RULE FOR FORMING QUESTIONS**

**Spanish question = Question word + verb + subject**

Examples:

* ¿Qué **comes** tú? → What do you eat?
* ¿Dónde **vives** tú? → Where do you live?
* ¿Cuándo **es** tu cumpleaños? → When is your birthday?

Spanish does **NOT** follow English order exactly.

# 🟩 **A. RULES FOR “QUÉ” (WHAT)**

Use **qué** for:

1. Definitions
2. Activities
3. Asking for general info
4. Asking what someone does/studies

Examples:

* ¿Qué es esto? → What is this?
* ¿Qué haces? → What are you doing?
* ¿Qué estudias? → What do you study?

❌ NEVER use “qué” for choosing between options.
Use “cuál” for that (next section).

---

# 🟩 **B. RULES FOR “CUÁL / CUÁLES” (WHICH / WHAT)**

Use **cuál** when:

1. Choosing from options
2. Asking for specific data (name, number, etc.)
3. Asking for someone's phone number, birthday, etc.

Examples:

* ¿Cuál prefieres? → Which do you prefer?
* ¿Cuál es tu nombre? → What is your name?
* ¿Cuál es tu número? → What is your number?

**Cuáles** = plural.

---

# 🟩 **C. RULES FOR “QUIÉN / QUIÉNES” (WHO)**

Use **quién** for 1 person.
Use **quiénes** for many people.

Examples:

* ¿Quién es ella? → Who is she?
* ¿Quiénes son ellos? → Who are they?

---

# 🟩 **D. RULES FOR “DE QUIÉN” (WHOSE / BELONGS TO WHO)**

Always use **de quién** to ask **possession**.

Formula:

### 👉 **¿De quién + es + object?**

Examples:

* ¿De quién es esta mochila? → Whose backpack is this?
* ¿De quién es el coche? → Whose car is it?

Plural object → "son":

* ¿De quién son estos libros? → Whose books are these?

---

# 🟩 **E. RULES FOR “DÓNDE” (WHERE)**

Asking about **location**.

* ¿Dónde vives? → Where do you live?
* ¿Dónde está tu casa? → Where is your house?

---

# 🟩 **F. RULES FOR “ADÓNDE” (TO WHERE)**

Asking **direction / movement**.

* ¿Adónde vas? → Where are you going (to)?
* ¿Adónde llevan este autobús? → Where does this bus go to?

---

# 🟩 **G. RULES FOR “CUÁNDO” (WHEN)**

Asking time, date, moment.

* ¿Cuándo es tu cumpleaños? → When is your birthday?
* ¿Cuándo empieza la clase? → When does class start?

---

# 🟩 **H. RULES FOR “CÓMO” (HOW)**

Asking **manner**, **condition**, or someone’s **description**.

* ¿Cómo estás? → How are you?
* ¿Cómo es ella? → What is she like? / How does she look?

---

# 🟩 **I. RULES FOR “POR QUÉ” (WHY)**

Asking **reason**.

* ¿Por qué estudias español? → Why do you study Spanish?

Answer uses **porque** (no accent).

* Porque quiero aprender. → Because I want to learn.

---

# 🟩 **J. RULES FOR “PARA QUÉ” (FOR WHAT PURPOSE)**

Asking purpose (future goal).

* ¿Para qué estudias español? → For what purpose do you study Spanish?
* Para viajar. → To travel.

---

# 🟩 **K. RULES FOR “CUÁNTO/A/OS/AS” (HOW MUCH/MANY)**

Always change form depending on gender/number.

| Spanish   | Meaning                  |
| --------- | ------------------------ |
| ¿Cuánto?  | How much? (masc.)        |
| ¿Cuánta?  | How much? (fem.)         |
| ¿Cuántos? | How many? (masc. plural) |
| ¿Cuántas? | How many? (fem. plural)  |

Examples:

* ¿Cuánto cuesta? → How much does it cost?
* ¿Cuántos estudiantes hay? → How many students are there?

---

# 🚫 **4. MOST COMMON MISTAKES (DON'T DO THESE)**

❌ **“¿Quién esta mochila?”**
Correct → **¿De quién es esta mochila?**

❌ **Using “qué” for selections**
Wrong → ¿Qué libro quieres?
Better → **¿Cuál libro quieres?**

❌ **For people, don’t use “qué”**
Wrong → ¿Qué es él?
Correct → **¿Quién es él?**

❌ **For birthday don’t use “qué”**
Wrong → ¿Qué es tu cumpleaños?
Correct → **¿Cuándo es tu cumpleaños?**
